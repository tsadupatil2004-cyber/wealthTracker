# WealthTracker 💰

A responsive personal finance and expense tracking web application
built using HTML5, CSS3 and JavaScript.

## Features

- Expense and income tracking
- Transaction history
- Spending visualization
- Category-based analysis
- CSV export
- Responsive design
- Dynamic dashboard

## Tech Stack

HTML5
CSS3
JavaScript

## How It Works

1. User adds income/expense
2. Transaction is categorized
3. Dashboard updates dynamically
4. Spending distribution is visualized
5. Transactions can be exported as CSV
